# Flux Intercomparison Environment (FLUXIE)

[![DOI](https://zenodo.org/badge/764175505.svg)](https://doi.org/10.5281/zenodo.19184134)
[![Documentation](https://readthedocs.org/projects/fluxie/badge/?version=latest)](https://fluxie.readthedocs.io)

Fluxie is a Python package for comparing greenhouse gas fluxes from inversion models. It provides a set of tools to read, process, and visualize flux data from different sources, allowing users to easily compare and analyze the results of different inversion models.

## Installation

```bash
git clone https://github.com/openghg/fluxie.git
cd fluxie
pip install -e .
```

Then run the example notebook `scripts/example_basics.ipynb` to get started.
