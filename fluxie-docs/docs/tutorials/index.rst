Tutorials
=========

The notebooks below walk through concrete workflows using fluxie.
They are executed against real test data shipped with the repository,
so every output shown is reproducible.

To run a notebook interactively, open it from the ``scripts/`` directory
in your Jupyter environment after completing the :doc:`../getting_started`
installation steps.
