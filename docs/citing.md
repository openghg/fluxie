# Citing fluxie

If fluxie contributes to a project that leads to a scientific publication,
please acknowledge it by citing the version you used, via Zenodo:

[![DOI](https://zenodo.org/badge/764175505.svg)](https://doi.org/10.5281/zenodo.19184134)

1. Open <https://doi.org/10.5281/zenodo.19184134>.
2. Choose the version of fluxie you used in your project. This selects the DOI
   of that version.
3. Use the citation field of the Zenodo page to get the citation in the format
   you need.

You can check the installed version with:

```python
import importlib.metadata
importlib.metadata.version("fluxie")
```

The citation metadata is also available in the
[`CITATION.cff`](https://github.com/openghg/fluxie/blob/devel/CITATION.cff) file
of the repository.

## Add your publication to the hall of fame

Once your work is published, please add it to the [Hall of fame](hall_of_fame.md).
It only takes a few minutes from your web browser, see
[how to add your publication](hall_of_fame.md#add-your-publication).
