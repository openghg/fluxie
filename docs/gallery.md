# Gallery

All the plots available in fluxie, produced with the test data shipped in
`data/tests`. The figures are generated each time the documentation is built,
so they always reflect the current code.
The code producing them is in
[`docs/gallery.py`](https://github.com/openghg/fluxie/blob/devel/docs/gallery.py).
